📌 Project Overview

This project focuses on analyzing social media advertising campaigns across Facebook and Instagram to evaluate performance, engagement, and profitability.
The goal is to help businesses make data-driven marketing decisions using key performance metrics and visual insights.

🎯 Objectives

Analyze campaign performance using key marketing metrics

Compare spend vs revenue across campaigns

Identify high-performing campaigns based on CTR and ROI

Build an interactive Power BI dashboard for decision-making

🛠 Tools & Technologies Used

Power BI – Data modeling, DAX, dashboard creation

CSV Dataset – Social media campaign data

DAX – Custom measures and KPIs

📂 Dataset Description

The dataset contains simulated social media advertising data with the following fields:

Date

Campaign_Name

Platform (Facebook / Instagram)

Impressions

Clicks

Spend

Conversions

Revenue

📐 Key Metrics Calculated (DAX Measures)

Total Impressions

Total Clicks

Total Spend

Total Revenue

CTR (Click Through Rate)

ROI (Return on Investment)

CPC (Cost Per Click)

📊 Dashboard Features

KPI Cards: Total Revenue, Total Spend, CTR, ROI

Campaign-wise Click Performance

Spend vs Revenue Comparison

ROI by Campaign

CTR by Platform (Facebook vs Instagram)

Interactive slicers for Platform and Campaign Name

🔍 Key Insights

Retargeting Ads generate the highest ROI, making them the most cost-effective campaigns

Instagram shows a higher CTR compared to Facebook, indicating stronger engagement

Higher ad spend does not always guarantee higher revenue

Budget optimization should focus on high-ROI and high-CTR campaigns
